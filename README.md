# Современный HTML 2026 на практике

Практическое руководство по возможностям современного HTML на примере создания законченного приложения **FocusBoard 2026** — персональной панели продуктивности.

Книга является практическим компаньоном к теоретическому материалу
[Modern HTML 2026](https://github.com/rustkas/Modern-HTML-2026).

---

## О чём эта книга

HTML снова стал полноценной частью веб-платформы: не только «разметкой», но и набором декларативных API браузера.

В этом руководстве вы не просто читаете про теги — вы **постепенно собираете рабочий проект**, в котором используются:

- семантическая структура и landmarks;
- `<dialog>`, Popover API, `<details>`;
- современные формы, валидация и accessibility;
- performance-атрибуты и Critical Rendering Path;
- View Transition API и Navigation API;
- Declarative Shadow DOM, Custom Elements, Templates;
- design tokens, SSR-мышление и Progressive Enhancement.

После прохождения книги у читателя остаются:

1. законченный проект **FocusBoard 2026**;
2. практические навыки работы с современным HTML;
3. библиотека переносимых шаблонов и чек-листов.

---

## Для кого книга

- фронтенд-разработчиков, которые хотят глубже использовать нативный HTML;
- тех, кто устал решать типовые UI-задачи только через JavaScript-библиотеки;
- разработчиков, работающих с SSR/гибридными архитектурами;
- всех, кто хочет собрать современный интерфейс на Web Platform API.

---

## Как устроено обучение

Каждая глава:

1. объясняет одну группу возможностей современного HTML;
2. сразу применяет их в проекте FocusBoard;
3. фиксирует структуру файлов и актуальное состояние кода;
4. готовит основу для следующей темы.

Принцип книги:

> **HTML → CSS → JavaScript enhancement**

Сначала смысл и базовая функциональность, затем представление, затем усиление UX.

---

## Проект FocusBoard 2026

**FocusBoard** — учебное, но реалистичное приложение:

- список задач;
- создание задачи через `<dialog>`;
- действия через Popover API;
- фильтры;
- разделы «Задачи / Заметки / Настройки»;
- компонентный UI на Web Components;
- design tokens;
- progressive enhancement и SSR-friendly разметка.

Итоговая структура проекта:

```text
focusboard-2026/
├── index.html
├── styles/
│   ├── main.css
│   └── tokens.css
├── scripts/
│   └── main.js
├── components/
│   ├── task-card.js
│   ├── filter-panel.js
│   └── README.md
├── docs/
│   ├── ssr-architecture.md
│   ├── progressive-enhancement.md
│   ├── audit-checklist.md
│   └── modern-html-checklist.md
├── patterns/
│   ├── README.md
│   ├── dialog-form.html
│   ├── popover-actions.html
│   ├── details-filters.html
│   ├── responsive-image.html
│   └── custom-element-card.js
├── images/
└── README.md
```

## Что получит читатель в результате

После проработки всех глав вы сможете:

- проектировать интерфейсы через семантику, а не через «div-суп»;
- использовать нативные HTML API вместо тяжёлых UI-зависимостей там, где это уместно;
- собирать переиспользуемые компоненты на Web Components;
- строить SSR-friendly и progressive-enhancement архитектуру;
- проводить базовый аудит семантики, a11y, performance и структуры проекта;
- переносить готовые паттерны в другие продукты.
