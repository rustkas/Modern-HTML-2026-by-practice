**Глава 2. Современная семантика и landmarks**

### Главная идея главы

Современный HTML — это не набор «красивых тегов», а язык описания смысла документа. Семантические элементы позволяют браузеру, скринридерам, поисковым системам и другим агентам понимать структуру страницы без анализа её внешнего вида. В 2026 году правильный выбор между `<article>`, `<section>`, `<nav>` и `<div>` — это уже не вопрос стиля, а архитектурное решение.

### Почему семантика стала важнее

Раньше семантика в основном помогала SEO и доступности. Сегодня она является источником данных сразу для нескольких подсистем:

- Accessibility Tree (landmarks и роли)
- Поисковые системы и AI-агенты
- Server-Side Rendering и гидратация
- Браузерные API и расширения
- Компонентные архитектуры

Использование правильных элементов сразу даёт браузеру информацию, которую раньше приходилось дублировать с помощью ARIA.

### Landmarks — основа навигации

Landmarks позволяют пользователям скринридеров быстро перемещаться между основными зонами страницы.

| Элемент     | Роль (Landmark)     | Когда использовать                          | Важные нюансы |
|-------------|---------------------|---------------------------------------------|-------------|
| `<header>`  | `banner`            | Шапка всего документа                       | Только на верхнем уровне `<body>` |
| `<nav>`     | `navigation`        | Основная или дополнительная навигация       | Желательно давать `aria-label` |
| `<main>`    | `main`              | Основное содержимое страницы                   | Только один на странице |
| `<aside>`   | `complementary`     | Дополнительная информация                   | Фильтры, сайдбар, связанный контент |
| `<footer>`  | `contentinfo`       | Подвал документа                            | Только на верхнем уровне `<body>` |
| `<search>`  | `search`            | Поисковая форма                             | Baseline Widely available с 2023 |
| `<form>`    | `form`              | Форма                                       | Только если есть доступное имя |

Важные правила:
- `<header>` и `<footer>` внутри `<article>`, `<section>`, `<aside>` или `<main>` **теряют** роль landmark.
- `<section>` становится landmark (`region`) только при наличии доступного имени (`aria-label` или `aria-labelledby`).
- На странице должен быть только один активный `<main>`.

### Семантические разделы

#### `<article>`
Используйте, когда блок можно представить как самостоятельную публикацию:
- задача;
- заметка;
- карточка проекта;
- комментарий.

#### `<section>`
Тематический раздел документа.  
Хорошее правило: если у блока есть свой заголовок — скорее всего это `<section>`.  
Чтобы `<section>` стал полезным для скринридеров, обязательно связывайте его с заголовком:

```html
<section aria-labelledby="filters-heading">
  <h2 id="filters-heading">Фильтры</h2>
  ...
</section>
```

#### `<div>` и `<span>`
Используйте только тогда, когда нет подходящего семантического элемента (например, для стилизации или группировки без смысла).

#### `index.html`

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="FocusBoard 2026 — современная персональная панель продуктивности, построенная на возможностях современного HTML">
  <meta name="theme-color" content="#0f172a">
  <title>FocusBoard 2026 — Задачи</title>
</head>
<body>
  <!-- ===== Шапка приложения (landmark: banner) ===== -->
  <header>
    <h1>FocusBoard</h1>
    <p>Персональная панель продуктивности</p>
  </header>

  <!-- ===== Основная навигация (landmark: navigation) ===== -->
  <nav aria-label="Основная навигация">
    <ul>
      <li><a href="#tasks" aria-current="page">Задачи</a></li>
      <li><a href="#notes">Заметки</a></li>
      <li><a href="#settings">Настройки</a></li>
    </ul>
  </nav>

  <!-- ===== Поиск (landmark: search) ===== -->
  <search>
    <form role="search" aria-label="Поиск по задачам и заметкам">
      <label for="site-search">Поиск</label>
      <input type="search" id="site-search" name="q" placeholder="Поиск задач и заметок…">
      <button type="submit">Найти</button>
    </form>
  </search>

  <!-- ===== Основное содержимое (landmark: main) ===== -->
  <main id="tasks">
    <header>
      <h2>Задачи</h2>
      <p>Активные задачи на сегодня</p>
    </header>

    <section aria-labelledby="active-tasks-heading">
      <h3 id="active-tasks-heading">Активные</h3>

        <header>
          <h4 id="task-1-title">Изучить современный HTML</h4>
        </header>

        <footer>
          <p>Приоритет: высокий</p>
        </footer>
      </article>

      <article class="task" aria-labelledby="task-2-title">
        <header>

        </header>

        <footer>
          <p>Приоритет: средний</p>
        </footer>
      </article>
    </section>

    <section aria-labelledby="completed-tasks-heading">
      <h3 id="completed-tasks-heading">Выполненные</h3>

          <p>Выполнено</p>
        </footer>

    </section>
  </main>

  <!-- ===== Боковая панель (landmark: complementary) ===== -->
  <aside aria-labelledby="sidebar-heading">
```
